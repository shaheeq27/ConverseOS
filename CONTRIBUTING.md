# 🤝 Contributing to ConverseOS

Thank you for contributing to **ConverseOS — The Enterprise AI Operating System**.

## Workflow
1. Fork and clone the repository.
2. Create a feature branch following `CODE_STYLE.md` (`feature/your-feature`).
3. Ensure type-checking passes: `npx tsc --noEmit`.
4. Ensure the build succeeds: `npm run build`.
5. Submit a detailed Pull Request.
